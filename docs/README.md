# docs/

Static assets referenced by the main README.

## What goes here

- `demo.gif` — short recording of the extension in action (capture → annotate → generate)
- `screenshots/settings.png` — the popup settings page
- `screenshots/widget.png` — the in-page widget during a session
- `screenshots/annotation.png` — the screenshot annotation editor
- `screenshots/generated-doc.png` — a generated AI doc

These filenames are referenced directly from the root `README.md`. Keep them in sync if you rename anything.
